# 🧑‍💻 About Me / Sobre mí

¡Hola! Soy **Yofer**, **Matemático orientado a la Ingeniería de Machine Learning e Inteligencia Artificial**. 

Mi pasión es conectar el rigor científico de las matemáticas puras con la ingeniería de software moderna para construir sistemas inteligentes, escalables y listos para producción. A diferencia de un enfoque clásico de "caja negra", me especializo en entender la optimización, el álgebra lineal y la estadística detrás de cada algoritmo para diseñar soluciones eficientes, predecibles y con un despliegue completo de extremo a extremo.

---

### 🚀 Mi Enfoque Tecnológico

*   🧠 **Core AI:** Machine Learning tradicional, Redes Neuronales (Deep Learning) e IA Basada en Reglas (Sistemas Expertos / Lógica Formal).
*   🐍 **Backend & APIs:** Desarrollo de arquitecturas sólidas y de alto rendimiento utilizando **Python** y frameworks de IA.
*   💻 **Full-Stack AI Interfaces:** Diseño y desarrollo de interfaces web nativas personalizadas utilizando **HTML, CSS y JavaScript** para conectar a los usuarios con los modelos matemáticos de forma intuitiva.
*   ☁️ **Cloud & Deployment:** Despliegue, alojamiento y escalado de aplicaciones de Inteligencia Artificial en entornos de producción utilizando **Render**.
